# Mastward
Sovereign, local-first mission-control for your AI coding agents. The engine runs on **your** computer — your keys and code never leave your machine, and you can pause the agent at any time.

## Download
- **macOS (Apple Silicon):** [Releases](../../releases/latest) — notarized by Apple, opens with no warning.
- Windows / iOS / Android: coming soon.

Nothing is sent to any server. No account required to run it.
